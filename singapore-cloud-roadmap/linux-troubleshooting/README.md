This repository documents my hands-on Linux troubleshooting practice and production incident simulations as part of my **Cloud & DevOps Engineer** roadmap.

---

## 📌 Goal

Develop production-grade diagnostic and troubleshooting skills for Linux systems operating in cloud environments (AWS, GCP, Azure, and On-Premise infrastructure).

---

## 🛠️ Topics Covered

- **Service & Log Analysis:** `systemd` management, `journalctl` deep-dives, and service failure recovery.
- **Performance & Resource Bottlenecks:** Investigating high Load Average, CPU throttling, and memory leaks.
- **Storage & Filesystem Issues:** Diagnosing full disks, I/O wait issues, inode exhaustion, and deleted open files.
- **Network & Connectivity:** SSH authentication issues, port conflicts, and firewall/security group debugging.
- **Incident Simulations:** Real-world scenarios inspired by production outages.
